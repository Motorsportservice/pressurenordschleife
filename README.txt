REIFENDRUCK TRACK TOOL

Start unter Windows
Öffne index.html in einem aktuellen Browser. Die Berechnung und das Stint-Log funktionieren ohne Internet. Daten bleiben im Browserprofil gespeichert.

Auf dem Smartphone
Die App ist für kleine Bildschirme optimiert. Für Installation als App und Offline-Nutzung muss der Ordner über eine HTTPS-Adresse bereitgestellt werden (zum Beispiel eigener Webspace). Öffne die Adresse in Safari/Chrome und wähle „Zum Home-Bildschirm“ bzw. „Installieren“. Das direkte Öffnen der Datei funktioniert für die Nutzung, unterstützt aber keine PWA-Installation.

Bedienung
Eingaben ausfüllen, Modus wählen und Kaltluftdrucke ablesen. „Stint speichern“ fragt optional die vier heißen Drücke ab. Die Differenz zum warmen Zieldruck erscheint im Log. CSV exportieren sichert die Stints als Tabelle.

Formel
Aus dem Blatt Advanced_Setup übernommen: Zieldruck effektiv = Basis + 0,03 bar im Quali-Modus − (Runden − 3) × 0,01 bar. Kaltwerte verwenden die jeweiligen Vorder-/Hinterachsformeln sowie Lufttemperatur, Streckentemperatur und Fahrstil. Drücke werden auf 0,01 bar gerundet.
